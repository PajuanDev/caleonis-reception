La V1 reprend le socle LobbyStack sous Caléonis Receptionist. Cette page décrit les limites connues du pilote, pas un engagement de disponibilité permanente.

**Repère de qualification : 15 octobre 2026.** Le pilote téléphonique et une création de rendez-vous Google ont été qualifiés dans leur configuration de test. Cela ne qualifie pas automatiquement chaque espace client.

| Parcours | État à retenir |
| --- | --- |
| Appels entrants téléphoniques | Qualifiés sur le numéro pilote et sa configuration. Test nécessaire pour un nouveau numéro. |
| Conversation au navigateur | Parcours présent et utilisé pour les essais ; microphone et origine autorisée nécessaires. |
| Résumé, transcription, audio privé | Qualifiés pour les appels pilotes disposant d’un enregistrement. Vérifier chaque fiche. |
| Création Google Calendar | Qualification pilote avec relecture directe chez Google. Vérifier agenda, mode et droits de votre espace. |
| Renouvellement OAuth Google | Qualification de durabilité en cours séparément ; aucune durée garantie. |
| Annulation et déplacement | Code et réglages présents ; qualification complète nécessaire avant usage client. |
| Messages | Boîte du produit. Peut être vide sans canal actif. |
| SMS du numéro pilote | Indisponibles : numéro Voice-only. |
| Réponse IA aux SMS | Non proposée en V1. |
| Transfert humain | Ne pas présenter comme opérationnel sans qualification téléphonique explicite. |
| Connaissances et import Web | Code présent ; contrôler traitement et réponses après chaque import. |
| Widget chat et voix | Parcours existant, nouvelles activations restreintes par défaut. |
| Équipe, API et webhooks | Parcours existants à qualifier avec rôles et services destinataires autorisés. |
| Tarifs, affiliation et portabilité | Aucune offre ou garantie non approuvée. |

## Avant une démonstration

Utilisez un scénario approuvé et des données fictives. Montrez la fiche de résultat plutôt que de déduire une action de la réponse orale seule.

Une démonstration de prise de message peut volontairement ne pas réserver de rendez-vous. Expliquez le périmètre du scénario.

## Pour les cabinets médicaux

Le pilote reste limité à l’accueil administratif sans données de santé. Aucune qualification HDS, garantie médicale ou traitement clinique n’est annoncé.

## Périmètre V1

Un seul agent par entreprise, sans Agent Builder ni nouvelle rubrique Canaux. Email IA, messageries sociales, orchestration omnicanale et téléphonie avancée relèvent d’un éventuel travail ultérieur.
