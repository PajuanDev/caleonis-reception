`POST https://receptionist.caleonis.com/api/v1/webhooks/{webhook_id}/test`

Cette fiche décrit le contrat du runtime Caléonis. Les identifiants, champs et descriptions techniques du schéma sont conservés pour éviter toute ambiguïté.

Queues a webhook.test event to this endpoint only.

## Authentification et permissions
Envoyez `Authorization: Bearer <clé API>`. Permission exigée : `webhooks:manage`.

<Warning>Cette opération produit un effet réel. Utilisez une entreprise de test autorisée ; aucun appel ne doit être exécuté pour simplement lire la référence.</Warning>

## Paramètres
| Champ | Emplacement | Type | Requis | Description |
| --- | --- | --- | --- | --- |
| `webhook_id` | path | string (uuid) | Oui | The webhook endpoint id. |

## Réponses
| HTTP | Description |
| --- | --- |
| `202` | Accepted |
| `400` | The request is invalid (invalid_request). |
| `401` | The API key is missing, invalid, or revoked (unauthorized). |
| `403` | The API key lacks the webhooks:manage scope (insufficient_scope). |
| `404` | Not found (not_found). |
| `409` | The request conflicts with the current state. |
| `429` | Too many requests (rate_limited). Wait for the Retry-After header's number of seconds. |

Les réponses d’erreur utilisent `error.code`, `error.message` et parfois `error.details`. Respectez `Retry-After` et conservez la même clé d’idempotence et le même corps pour reprendre une création prise en charge.

## Exemple HTTP

```http
POST /api/v1/webhooks/{webhook_id}/test HTTP/1.1
Host: receptionist.caleonis.com
Authorization: Bearer <clé conservée côté serveur>
```
