`message.taken`

Ce webhook envoie un POST signé vers une destination publique HTTPS autorisée. Cette fiche documente le contrat réel de l’événement ; lire la page ne crée aucun abonnement.

## En-têtes et vérification
| En-tête | Requis | Description |
| --- | --- | --- |
| `webhook-id` | Oui | Event id. The same for every retry of this event. |
| `webhook-timestamp` | Oui | Unix time in seconds when this attempt was signed. |
| `webhook-signature` | Oui | Space-separated signatures, each v1,&lt;base64 HMAC-SHA256&gt;. |

Vérifiez la signature sur le corps brut avec Standard Webhooks et refusez un horodatage trop ancien. Dédupliquez durablement `id` avant de produire un effet. Les événements peuvent être relivrés ou arriver dans un ordre différent.

## Accusé de réception et reprises

Acceptez durablement puis répondez 2xx sous 10 secondes. Les échecs sont repris selon le calendrier de la version déployée. Un événement de réservation ne prouve ni synchronisation externe ni SMS/email livré. Voir le [guide complet des webhooks](/api/webhooks) et le [schéma OpenAPI](/api-reference/openapi.json).
