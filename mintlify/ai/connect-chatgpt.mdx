L'URL du serveur est `https://receptionist.caleonis.com/api/mcp`. Si vous auto-hébergez Caléonis Receptionist, remplacez `receptionist.caleonis.com` par votre propre domaine. ChatGPT s'y connecte depuis Internet : un Caléonis Receptionist auto-hébergé a donc besoin d'une adresse HTTPS publique.

Consultez [Serveur MCP](/ai/mcp) pour savoir quels outils chaque autorisation débloque.

## ChatGPT

Vérifiez dans votre version de ChatGPT que l'ajout d'un serveur MCP distant est disponible et autorisé par votre organisation. Les menus et offres de ce logiciel tiers ne constituent pas une fonction incluse de Caléonis.

1. Ouvrez le parcours d'ajout MCP proposé par votre version.
2. Saisissez `https://receptionist.caleonis.com/api/mcp` et le mode d'authentification effectivement ouvert dans votre espace.
3. En cas de consentement OAuth, vérifiez l'entreprise et limitez les permissions.
4. Testez `get_business`, un refus d'action sans permission et la révocation.

La documentation officielle des [connexions MCP OpenAI](https://developers.openai.com/api/docs/guides/tools-connectors-mcp) précise les paramètres API. La connexion du SaaS avec chaque client doit être qualifiée séparément. Ne collez jamais une clé dans une conversation.

## API Responses d'OpenAI

L'API Responses appelle les serveurs MCP distants pour vous. Passez une clé API dans `headers` :

```bash
curl https://api.openai.com/v1/responses \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "model": "gpt-6-luna",
    "tools": [{
      "type": "mcp",
      "server_label": "lobbystack",
      "server_url": "https://receptionist.caleonis.com/api/mcp",
      "headers": { "Authorization": "Bearer '"$LOBBYSTACK_API_KEY"'" },
      "require_approval": "always"
    }],
    "input": "Who called yesterday and asked for a callback?"
  }'
```

`require_approval: "always"` arrête l'API avant chaque appel d'outil pour que votre code puisse le confirmer. N'assouplissez ce réglage que pour les clés qui ont seulement des portées de lecture.

## Codex

Ajoutez Caléonis Receptionist à `~/.codex/config.toml`. Codex lit la clé API dans la variable d'environnement que vous indiquez :

```toml ~/.codex/config.toml
[mcp_servers.lobbystack]
url = "https://receptionist.caleonis.com/api/mcp"
bearer_token_env_var = "LOBBYSTACK_API_KEY"
```

Exportez `LOBBYSTACK_API_KEY` dans votre terminal, lancez Codex et demandez-lui d'appeler `get_business` pour vérifier la connexion.

Référence officielle pour la configuration Codex : [MCP](https://developers.openai.com/codex/mcp).
