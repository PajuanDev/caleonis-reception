Le code contient un serveur MCP à l’adresse `https://receptionist.caleonis.com/api/mcp`, avec transport Streamable HTTP.

Cette interface expose les données et actions de l’entreprise autorisée. Sa présence ne signifie pas que tous les clients ou actions ont été qualifiés sur le SaaS. Elle ne crée aucun Agent Builder ni plusieurs agents métier Caléonis.

## Accès

Deux mécanismes existent dans le code : clé API et consentement OAuth. Choisissez seulement le mécanisme effectivement ouvert dans votre environnement.

Commencez par une clé en lecture limitée ou un consentement de lecture. Vérifiez l’entreprise affichée avant d’autoriser un client externe.

Pour les [clés API](/api/authentication), utilisez l’en-tête `Authorization: Bearer <clé>` uniquement dans un client qui le stocke de manière sûre.

## Outils présents

| Outils | Permission |
| --- | --- |
| `get_business`, `list_services`, `list_staff` | `business:read` |
| `update_business_hours` | `business:write` |
| `list_calls`, `get_call` | `calls:read` |
| `search_contacts`, `get_contact` | `contacts:read` |
| `create_contact`, `update_contact` | `contacts:write` |
| `list_appointments`, `get_appointment`, `check_availability` | `appointments:read` |
| `book_appointment`, `cancel_appointment`, `reschedule_appointment` | `appointments:write` |
| `list_messages` | `messages:read` |
| `add_knowledge` | `knowledge:write` |

Les règles de réservation et l’isolation par entreprise restent applicables. Une instruction d’un assistant ne doit pas contourner un refus.

## Qualifier une connexion

1. Vérifiez le client et l’endroit où il conserve les secrets.
2. Connectez uniquement un espace de test autorisé.
3. Lisez les informations d’entreprise.
4. Vérifiez qu’une action sans permission échoue.
5. Révoquez l’accès de test et vérifiez son refus.

Les changements de rendez-vous ou d’horaires nécessitent une autorisation explicite de votre organisation. Consultez le [guide d’usage](/ai/lobbystack-skill) et les [erreurs API](/api/requests).

Les menus et conditions des logiciels clients évoluent. Les guides suivants décrivent les vérifications à faire, sans garantir un chemin de menu ou un abonnement tiers.
