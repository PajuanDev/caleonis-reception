Cette page concerne une intégration technique facultative. Aucun abonnement tiers ni connecteur Caléonis préinstallé n’est promis.

## Avant de connecter

Vérifiez dans votre version du client Claude qu’il accepte un serveur MCP distant avec le mécanisme d’authentification prévu. Les possibilités varient selon le client et l’offre.

Préparez un espace de test, les permissions nécessaires et l’accord de votre organisation sur le partage de données avec ce client.

## Paramètres à vérifier

- Serveur : `https://receptionist.caleonis.com/api/mcp`.
- Transport : Streamable HTTP.
- Accès : OAuth si proposé et qualifié, ou clé API si le client accepte un en-tête sécurisé.

Ne placez pas une clé d’API dans une instruction de conversation ou une URL.

## Premier essai

Demandez seulement la lecture du nom de l’entreprise. Comparez le résultat au tableau de bord. Testez ensuite le refus d’une action hors permissions.

N’utilisez pas la création de rendez-vous comme premier test. Une action réussie peut avoir un effet réel sur l’agenda.

## Déconnecter

Supprimez la connexion du client et révoquez la clé ou l’autorisation côté Caléonis lorsque le contrôle est proposé. Vérifiez que l’ancien accès échoue.

Voir le [serveur MCP](/ai/mcp) pour les outils et limites.
