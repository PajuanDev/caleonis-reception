---
title: "Préparer les webhooks"
description: "Connecter un service technique et vérifier la réception d’un événement."
---
Un webhook transmet un événement de votre entreprise à un service que vous contrôlez. Il nécessite une configuration technique ; ce n’est pas une notification email ou SMS.

## Configurer avec un administrateur

1. Ouvrez **Intégrations > Webhooks**.
2. Ajoutez une adresse HTTPS publique autorisée.
3. Choisissez uniquement les événements nécessaires.
4. Conservez le secret de signature dans le gestionnaire de secrets du destinataire.
5. Lancez un événement de test autorisé.
6. Comparez le journal de livraison et la réception côté destinataire.

N’utilisez pas une adresse de production qui déclencherait une facture, une notification client ou une autre action réelle pendant le test.

## Protéger les données

Le destinataire reçoit des informations de votre entreprise. Vérifiez son habilitation et limitez les données qu’il conserve.

Le secret est sensible et peut n’être montré qu’une fois. Ne le mettez pas dans une page publique ou une capture d’écran.

## Livraison en échec

Consultez le statut et la réponse HTTP dans le journal. Corrigez le destinataire avant un renvoi manuel. Le destinataire doit reconnaître un événement déjà traité pour éviter les doublons.

Le parcours complet n’est qualifié qu’après réception et vérification de signature. Consultez la [référence technique](/api/webhooks) pour les en-têtes et événements.
