La page **Gestion > Intégrations** regroupe les connecteurs proposés pour l’entreprise active.

| Intégration | Usage | Limite |
| --- | --- | --- |
| [Google Calendar](/integrations/google-calendar) | Disponibilités et événements de réservation. | Compte, droits, agenda et synchronisation à contrôler. |
| [Webhooks](/integrations/webhooks) | Événements vers un service technique autorisé. | Configuration et test du destinataire nécessaires. |
| [SMS](/integrations/sms) | Messages ou alertes selon capacités. | Indisponibles sur le numéro pilote Voice-only. |
| [Widget](/settings/widget) | Chat et voix Web avec clés existantes autorisées. | Nouvelles activations restreintes. |

L’API et le MCP existants sont documentés dans la partie développeurs. Leur présence ne vaut pas validation de l’accès ou de chaque action en production.

## Connecter avec le bon rôle

Utilisez un compte propriétaire ou administrateur lorsque la gestion du connecteur l’exige. Vérifiez l’entreprise sélectionnée avant d’autoriser un compte externe.

Accordez uniquement les droits nécessaires. Ne copiez pas de secret dans une conversation, une capture d’écran ou le navigateur.

## Vérifier le résultat

Une carte « connecté » indique un état de connexion. Qualifiez ensuite l’action métier : événement relu chez Google, requête API autorisée ou webhook effectivement reçu.

Aucune intégration email IA, WhatsApp ou réseau social n’est annoncée dans la V1. Un service d’email transactionnel n’est pas une boîte email gérée par l’agent.
