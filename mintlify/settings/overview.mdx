Les **Réglages** rassemblent les préférences personnelles et celles de l’entreprise. Certaines actions exigent un rôle propriétaire ou administrateur.

| Page | Usage |
| --- | --- |
| [Compte](/settings/account) | Identité du compte et sécurité d’accès. |
| [Équipe](/settings/team) | Membres, invitations et rôles. |
| [Notifications](/settings/notifications) | Préférences et disponibilité des canaux. |
| [Numéro de téléphone](/settings/phone-number) | Numéro attribué et capacités. |
| [Widget](/settings/widget) | Configuration des clés Web existantes autorisées. |
| [Usage](/billing/usage) | Consommation et limites affichées. |
| [Clés d’API](/api/authentication) | Accès techniques limités à l’entreprise. |

## Modifier un réglage

Vérifiez l’entreprise, lisez le message d’effet et enregistrez. Certains contrôles enregistrent immédiatement ; d’autres exigent une confirmation.

Après un changement de numéro, de calendrier ou de politique de réservation, qualifiez le parcours concerné avant usage client.

## Fonction absente

Une page peut dépendre du rôle, des capacités ou de la version déployée. Ne considérez pas une fonction comme incluse dans votre offre sur la seule base de ce guide. Consultez les [capacités](/support/availability) puis l’administrateur de votre espace.
