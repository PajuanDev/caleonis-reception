# Contribuer au centre d’aide

Modifiez les guides MDX puis la navigation dans `docs.json` si nécessaire. Préservez les routes existantes ou ajoutez une redirection.

## Avant une proposition de modification

1. Vérifiez les libellés et actions dans le code courant de l’application.
2. Distinguez la fonction présente d’une fonction activée et qualifiée.
3. Rédigez en français ; gardez les exemples sans données personnelles.
4. Préservez les mentions MIT et la provenance des illustrations.
5. Lancez `pnpm docs:validate` et `pnpm docs:broken-links`.
6. Vérifiez l’aperçu responsive du site d’aide.
7. Ouvrez une proposition en brouillon, sans publication automatique.

Consultez `README.md` pour les commandes d’aperçu. Les anciens noms de variables et packages ne doivent pas être remplacés pour la marque.
