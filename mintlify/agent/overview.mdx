La section **Agent** détermine le comportement de votre réceptionniste IA. Elle se divise en Paramètres IA, Connaissances, Services et Règles.

Les modifications s'appliquent aux nouveaux appels et aux nouvelles réponses du chat du site Web. Elles ne modifient pas les appels ni les messages passés.

## Comment la configuration est utilisée

Caléonis Receptionist prépare les réglages enregistrés de l'agent pour chaque appel en direct. Le comportement reste ainsi stable pendant toute la conversation.

Pour le chat du site Web, Caléonis Receptionist s'appuie sur le contexte actuel de l'entreprise et sur l'état enregistré de la conversation pour générer les réponses.

## Configuration minimale avant les vrais appelants

Avant de renvoyer de vrais appels, vérifiez que :

- Votre message d'accueil nomme votre entreprise et indique clairement à quoi l'appelant peut s'attendre.
- La langue de repli est définie pour les cas où la langue de l'appelant n'est pas claire.
- Un numéro de transfert est enregistré si vous voulez qu'un humain puisse prendre le relais en direct.
- Vos entrées de connaissances couvrent les heures d'ouverture, l'adresse, les services, les prix, les politiques et les questions fréquentes des appelants.
- Vos services et votre connexion Google Calendar sont prêts avant de compter sur la prise de rendez-vous ou les modifications de rendez-vous.

## Périmètre Caléonis V1

Un seul agent est configuré par entreprise. Les rubriques IA, Connaissances, Services et Règles ne constituent pas un Agent Builder. Les modifications sont prises en compte dans les nouveaux échanges ; elles ne réécrivent pas un appel déjà commencé. Réalisez un nouveau test après enregistrement et traitement des sources.

Une prise de message est le repli pendant qu'un transfert reste indisponible. Elle n'initie aucun appel sortant automatique. Voir [Capacités et qualification](/support/availability).
