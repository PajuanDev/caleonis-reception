## Préparer les informations

Commencez par les faits : horaires, adresse, zone desservie, services et procédure de rappel. Ajoutez les consignes de comportement ensuite.

Les réglages sont utilisés pour les nouveaux échanges. Un appel déjà démarré conserve son contexte ; une modification n’en réécrit pas la transcription.

## Vérifier une modification

Enregistrez, attendez le traitement des connaissances si nécessaire, puis démarrez un **nouveau** test. Posez une question correspondant exactement à la modification.

Si l’agent invente une réponse, corrigez la source ou ajoutez une règle de prise de message. Ne lui donnez pas une instruction qui promet un canal ou une action indisponible.

## Limites V1

Il n’existe ni catalogue multi-agents ni Agent Builder dans ce parcours. Les intégrations techniques et assistants développeurs documentés séparément ne créent pas de nouveaux agents métier dans votre tableau de bord.
