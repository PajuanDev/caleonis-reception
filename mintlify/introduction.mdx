Caléonis Receptionist est le réceptionniste IA de votre entreprise. Un seul agent utilise votre accueil, vos connaissances, vos services et vos règles pour répondre aux appels.

Vous retrouvez l’activité dans le [tableau de bord](https://receptionist.caleonis.com). Ce centre d’aide décrit la version issue de LobbyStack, adaptée à Caléonis. La disponibilité dépend de votre espace, de votre numéro et des intégrations configurées.

## Retrouver les rubriques de l’application

| Rubrique | Entrées |
| --- | --- |
| **Général** | Accueil, Appels, Messages, Contacts |
| **Agent** | Paramètres IA, Connaissances, Services, Règles |
| **Gestion** | Analytique, Intégrations, Réglages |
| **Premiers pas** | Les étapes de préparation de votre entreprise |

Les rendez-vous sont accessibles depuis les vues qui les proposent. Il n’existe pas de catalogue de plusieurs agents à créer en V1.

## Avant d’accueillir vos clients

Commencez par le [guide de démarrage](/quickstart), puis consultez les [capacités et limites](/support/availability). Un réglage visible n’est pas une preuve qu’une intégration a été qualifiée dans votre espace.

<Warning>
Le numéro pilote français est Voice-only : les appels entrants sont disponibles, les SMS ne le sont pas sur ce numéro. Le transfert humain, la portabilité et les offres commerciales nécessitent une validation spécifique.
</Warning>

Pour un cabinet médical, limitez tout test à l’accueil administratif sans données de santé. Aucune qualification HDS ni garantie d’usage médical n’est annoncée.

## Ce que le réceptionniste rassemble

- Les appels entrants sur le numéro attribué après validation opérateur.
- Un accueil enregistré et une langue de repli lorsque celle de l'appelant n'est pas claire.
- Les réponses factuelles issues de textes, de documents traités et de pages publiques autorisées.
- La prise de rendez-vous lorsque service, horaires, mode de réservation et agenda le permettent.
- Les demandes de rappel pour votre équipe, sans appel sortant automatique.
- Les résumés, transcriptions, enregistrements disponibles, contacts et rendez-vous dans le bon espace.
- Les accès techniques autorisés par API, MCP et webhooks, documentés séparément.

Les appels PSTN, la consultation privée d'un appel et une réservation dans un agenda Google de test ont été vérifiés dans le pilote. Chaque nouvel espace et chaque action non testée nécessitent leur propre contrôle.
