`POST https://receptionist.caleonis.com/api/v1/contacts`

This page describes the Caléonis runtime contract. Schema field names and technical descriptions are preserved verbatim for integration accuracy.

Returns 409 conflict when a contact with the same phone number exists.

## Authentication and permissions
Send `Authorization: Bearer <API key>`. Required scope: `contacts:write`.

<Warning>This operation has a real effect. Use an authorized test business; reading the reference does not call the operation.</Warning>

## Parameters
| Field | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Idempotency-Key` | header | string | No | A unique value, up to 255 characters, that makes retries of this request safe for 24 hours. |

## Request body

`Content-Type: application/json`

| Field | Type | Required | Description / constraints |
| --- | --- | --- | --- |
| `name` | string | No |  minLength=1; maxLength=200 |
| `phone` | string | No | Phone number in E.164 format. pattern="^\\+[1-9]\\d{6,14}$" |
| `email` | string (email) | No |  maxLength=320 |
| `locale` | string | No |  enum=["en", "fr"] |
| `timezone` | string | No |  minLength=1; maxLength=80 |

## Responses
| HTTP | Description |
| --- | --- |
| `201` | Created |
| `400` | The request is invalid (invalid_request). |
| `401` | The API key is missing, invalid, or revoked (unauthorized). |
| `403` | The API key lacks the contacts:write scope (insufficient_scope). |
| `409` | The request conflicts with the current state. |
| `429` | Too many requests (rate_limited). Wait for the Retry-After header's number of seconds. |

Errors use error.code, error.message and sometimes error.details. Respect Retry-After and reuse the same idempotency key and body when retrying a supported creation.

## HTTP example

```http
POST /api/v1/contacts HTTP/1.1
Host: receptionist.caleonis.com
Authorization: Bearer <server-side key>
Content-Type: application/json
```
