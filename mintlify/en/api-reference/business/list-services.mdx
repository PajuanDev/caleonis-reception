`GET https://receptionist.caleonis.com/api/v1/services`

This page describes the Caléonis runtime contract. Schema field names and technical descriptions are preserved verbatim for integration accuracy.

Lists the active services customers can book.

## Authentication and permissions
Send `Authorization: Bearer <API key>`. Required scope: `business:read`.

## Parameters
No path or query parameters.

## Responses
| HTTP | Description |
| --- | --- |
| `200` | OK |
| `400` | The request is invalid (invalid_request). |
| `401` | The API key is missing, invalid, or revoked (unauthorized). |
| `403` | The API key lacks the business:read scope (insufficient_scope). |
| `429` | Too many requests (rate_limited). Wait for the Retry-After header's number of seconds. |

Errors use error.code, error.message and sometimes error.details. Respect Retry-After and reuse the same idempotency key and body when retrying a supported creation.

## HTTP example

```http
GET /api/v1/services HTTP/1.1
Host: receptionist.caleonis.com
Authorization: Bearer <server-side key>
```
