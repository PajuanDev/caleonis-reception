`POST https://receptionist.caleonis.com/api/v1/appointments`

This page describes the Caléonis runtime contract. Schema field names and technical descriptions are preserved verbatim for integration accuracy.

Books only when the business's booking_mode is instant. Returns 409 booking_requires_confirmation in request mode and 409 booking_disabled when booking is off.

## Authentication and permissions
Send `Authorization: Bearer <API key>`. Required scope: `appointments:write`.

<Warning>This operation has a real effect. Use an authorized test business; reading the reference does not call the operation.</Warning>

Respect booking mode, hours, availability, time zone and permissions. An application result does not prove Google synchronization or a notification. The French Voice-only line cannot send SMS.

## Parameters
| Field | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Idempotency-Key` | header | string | No | A unique value, up to 255 characters, that makes retries of this request safe for 24 hours. |

## Request body

`Content-Type: application/json`

| Field | Type | Required | Description / constraints |
| --- | --- | --- | --- |
| `service_id` | string (uuid) | Yes | Stable identifier (UUID). |
| `starts_at` | string (date-time) | Yes | Start time. Use a starts_at value from GET /availability. |
| `contact_id` | string (uuid) | No | An existing contact with a phone number. Provide contact_id or contact_phone. |
| `contact_phone` | string | No | Phone number in E.164 format. pattern="^\\+[1-9]\\d{6,14}$" |
| `contact_name` | string | No |  minLength=1; maxLength=200 |
| `staff_id` | string (uuid) | No | Book with this active staff member. Without it, the receptionist picks one who is free. |
| `sms_consent` | boolean | No | True only if the customer agreed to receive confirmation and reminder texts. |

## Responses
| HTTP | Description |
| --- | --- |
| `201` | Created |
| `400` | The request is invalid (invalid_request). |
| `401` | The API key is missing, invalid, or revoked (unauthorized). |
| `403` | The API key lacks the appointments:write scope (insufficient_scope). |
| `409` | The request conflicts with the current state. |
| `429` | Too many requests (rate_limited). Wait for the Retry-After header's number of seconds. |

Errors use error.code, error.message and sometimes error.details. Respect Retry-After and reuse the same idempotency key and body when retrying a supported creation.

## HTTP example

```http
POST /api/v1/appointments HTTP/1.1
Host: receptionist.caleonis.com
Authorization: Bearer <server-side key>
Content-Type: application/json
```
