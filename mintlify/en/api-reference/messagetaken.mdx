`message.taken`

This webhook sends a signed POST to an authorized public HTTPS endpoint. This page documents the actual event contract; reading it creates no subscription.

## Headers and verification
| Header | Required | Description |
| --- | --- | --- |
| `webhook-id` | Yes | Event id. The same for every retry of this event. |
| `webhook-timestamp` | Yes | Unix time in seconds when this attempt was signed. |
| `webhook-signature` | Yes | Space-separated signatures, each v1,&lt;base64 HMAC-SHA256&gt;. |

Verify the raw-body signature with Standard Webhooks and reject stale timestamps. Durably deduplicate id before producing effects. Events can be redelivered or arrive out of order.

## Acknowledgement and retries

Accept durably, then return 2xx within 10 seconds. Failed attempts follow the deployed retry schedule. A booking event does not prove external synchronization or delivered SMS/email. See the [complete webhook guide](/en/api/webhooks) and [OpenAPI schema](/api-reference/openapi.json).
