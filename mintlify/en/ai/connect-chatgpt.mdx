The server URL is `https://receptionist.caleonis.com/api/mcp`. Replace `receptionist.caleonis.com` with your own domain if you self-host. ChatGPT connects to it from the internet, so a self-hosted Caléonis Receptionist needs a public HTTPS address.

See [MCP server](/en/ai/mcp) for the tools each permission unlocks.

## ChatGPT

Check that your installed ChatGPT version and organization permit adding a remote MCP server. Third-party menus and plans are not a Caléonis entitlement.

1. Open the MCP connection flow offered by your version.
2. Enter `https://receptionist.caleonis.com/api/mcp` and the authentication mode actually enabled for your workspace.
3. If OAuth consent is shown, verify the business and limit permissions.
4. Test `get_business`, a denied action and revocation.

The official [OpenAI MCP documentation](https://developers.openai.com/api/docs/guides/tools-connectors-mcp) describes API parameters. Each SaaS/client connection needs separate qualification. Never paste a key into a conversation.

## OpenAI Responses API

The Responses API calls remote MCP servers for you. Pass an API key in `headers`:

```bash
curl https://api.openai.com/v1/responses \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "content-type: application/json" \
  -d '{
    "model": "gpt-6-luna",
    "tools": [{
      "type": "mcp",
      "server_label": "lobbystack",
      "server_url": "https://receptionist.caleonis.com/api/mcp",
      "headers": { "Authorization": "Bearer '"$LOBBYSTACK_API_KEY"'" },
      "require_approval": "always"
    }],
    "input": "Who called yesterday and asked for a callback?"
  }'
```

`require_approval: "always"` makes the API stop before each tool call so your code can confirm it. Loosen it only for keys with read scopes.

## Codex

Add Caléonis Receptionist to `~/.codex/config.toml`. Codex reads the API key from the environment variable you name:

```toml ~/.codex/config.toml
[mcp_servers.lobbystack]
url = "https://receptionist.caleonis.com/api/mcp"
bearer_token_env_var = "LOBBYSTACK_API_KEY"
```

Export `LOBBYSTACK_API_KEY` in your shell, start Codex, and ask it to call `get_business` to check the connection.

Official Codex configuration reference: [MCP](https://developers.openai.com/codex/mcp).
