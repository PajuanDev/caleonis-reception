The **Agent** section controls how your AI receptionist behaves. It is split into AI settings, Knowledge, Services, and Rules.

Changes apply to new calls and website chat responses. They do not rewrite calls or messages that already happened.

## How configuration is used

Caléonis Receptionist prepares the saved Agent settings for each live call, so callers get stable behavior for the duration of the conversation.

For website chat, Caléonis Receptionist uses the current business context and saved conversation state when generating replies.

## Minimum setup for real callers

Before forwarding production calls, check that:

- Your greeting names your business and sets the right expectation.
- The fallback language is set for cases where the caller's language is unclear.
- A transfer number is saved if you want live human handoff.
- Your knowledge entries include hours, location, services, pricing, policies, and common caller questions.
- Your service entries and Google Calendar connection are ready before you rely on appointment booking or appointment changes.

## One receptionist per business

These pages configure one agent. There is no multi-agent catalogue or Agent Builder in V1. Changes are used for new conversations; begin a new test after saving and processing. A fallback callback task does not start an automatic outbound call.
